# Projects Hub

Live at https://cadensauce.github.io/

## Add a project
Edit `projects.js` and copy one `{ ... }` block. Fill in `name`, `desc` and `status`
("Live", "In development", "Paused" or "Archived"). Add `url` to make the card a link,
`notes` for small tags, and `repo` ("owner/name") to show when it was last updated
(or `updated: "YYYY-MM-DD"` if it has no repo). Commit and push: GitHub Pages updates in about a minute.
